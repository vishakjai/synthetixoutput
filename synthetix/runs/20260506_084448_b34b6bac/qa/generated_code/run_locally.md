## Notes

- Replace `JWT_SIGNING_KEY` with a real 32-byte secret before any non-local use.
- The Postgres volume `dbdata` persists across restarts; remove with `docker-compose down -v` to reset.
- Each backend service exposes its API on the URL above. Hit it with `curl`, Postman, or the Swagger UI.
